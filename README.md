# Maziyar Bahrami — Personal Website

Static personal website for **https://mazbahrami.github.io**.

## Publish This Update

1. Extract the ZIP.
2. Open `mazbahrami/mazbahrami.github.io` on GitHub.
3. Choose **Add file → Upload files**.
4. Drag every file and folder from the extracted directory into the upload area.
5. Commit directly to `main`.
6. Wait for the GitHub Pages workflow to finish.

## Current Published Essay

- Page: `writing/the-missing-control-loop/index.html`

- Listing page: `writing/index.html`

## Add Another Essay Using the Current Static Structure

1. Copy the folder `writing/the-missing-control-loop/` and rename it with the new article slug.
2. Replace the title, metadata, table of contents, and article body in its `index.html`.
3. Add a card or featured link to `writing/index.html`.
4. Optionally update the homepage latest-writing section in `index.html`.
5. Add the new URL to `sitemap.xml`.

For frequent publishing, a later migration to Astro/MDX will make this process automatic.

## Update the CV

Replace `assets/documents/Maziyar-Bahrami-CV.pdf` with a new PDF using the same filename.
