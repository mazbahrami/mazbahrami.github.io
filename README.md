# Maziyar Bahrami — Personal Website

Static personal website for **https://mazbahrami.github.io**.

## Publish an Update

1. Extract the ZIP.
2. Open the GitHub repository `mazbahrami/mazbahrami.github.io`.
3. Choose **Add file → Upload files**.
4. Drag every file and folder from the extracted directory into the upload area.
5. Commit directly to `main`.
6. Wait for the GitHub Pages workflow to finish.

## Update the CV

Replace `assets/documents/Maziyar-Bahrami-CV.pdf` with a new PDF using the same filename.

## Add Writing in the Future

For occasional posts, add a folder such as `writing/article-title/index.html`, link it from `writing/index.html`, and add its URL to `sitemap.xml`. For regular publishing, migrate the site to Astro/MDX.
